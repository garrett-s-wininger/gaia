# Components

Each component has a home for its scope, design decisions and implementation milestones. Research can inform several components without turning an experimental representation into a shared protocol.

| Component | Start here | Maturity |
| --- | --- | --- |
| Source control | [Guide](source-control/README.md) | Consolidated design and accepted first milestone. |
| Dependencies | [Guide](dependencies/README.md) | Python-specific research; general interfaces open. |
| Compiler tools | [Guide](compiler/README.md) | Native and managed compiler research with measured results. |
| Editor | [Guide](editor/README.md) | Planned; design questions only. |
| Artifact host | [Guide](artifact-host/README.md) | Initial transfer design/research; no production service or agreed public protocol. |

The [platform direction](../docs/platform.md) describes the proposed connections. To add a component, follow the [repository guide](../docs/repository-layout.md). A new directory is a place to develop a design, not evidence that its implementation or requirements have already been agreed.
