# .NET research prospects

Extend the measured application-only composite test to a larger real command before selecting a distribution policy. Preserve shipping R2R, tiered compilation and JIT fallback; count producer time, native image size and update coupling. More repetitions or a distinct workload are useful before generalizing the small six-of-seven result.

Reflection-metadata precomputation belongs in a tool that actually discovers many types/plugins at startup. The initial compiler CLI does not establish that bottleneck, so it supplies no reflection-cache gain. Any future provider must retain dynamic-loading/attribute behavior and invalidation identities.

Runtime/target/library version changes may require rebuilding a composite group. Measure compatibility and fallback behavior when designing shared artifact storage or remote delivery. This experiment uses one pinned Linux x64 runtime and does not choose a servicing protocol.

The [first report](../../experiments/dotnet_startup/results/initial/REPORT.md) records the already-optimized baseline and complete operation, rather than comparing with disabled runtime optimizations.
