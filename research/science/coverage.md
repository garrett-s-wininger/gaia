# Coverage and remaining boundaries

All proposed families received a bounded implementation or experiment. That does not make every family a production implementation. The [overview](README.md) links the reports and measurements.

| Direction | Evidence class | Implemented boundary | Remaining question |
| --- | --- | --- | --- |
| Set reconciliation / information theory | Actual algorithms | Sorted, Merkle and IBLT inventories with exact commitment and fallback | Native construction and real remote exchange amortization |
| Patch theory | Checked finite laws | Contextual file operations, inversion, conservative commutation, full snapshots | Rich edits, conflicts and durable repository transactions |
| Lattices / coordination | Checked model | Retain alternatives, joins, expected-generation authority counterexample | Concurrent durable implementation and review semantics |
| Incremental graphs / dataflow | Actual algorithms and compiler fixture | Cycles, removals, negatives, shadowing, environment, refreshed dependencies | Broader SDK effects and integration into the production graph |
| Parallel scheduling / networking | Simulations plus actual delivery | Safe-boundary cancellation models, task-duration calibration, actual loopback HTTP/binary batching | Actual compiler scheduling callbacks, fairness under sustained loads and WAN behavior |
| Pebbling / retention | Model with tiny exact oracle | Dependency leases, scratch and recomputation | Real allocation attribution and concurrent service budgets |
| Reinforcement / foraging / modularity | Algorithms and models | Decay/locality policies, coarse versus fine invalidation, held-out placement | Unseen workloads and policies that beat cheaper baselines |
| Feedback control | Actual service and scheduling models | Damped request concurrency, bounded exploration | Disturbance response with real network/device measurements |
| Bounded optimization | Actual search | Equal evaluation budgets for grid, random and evolution | Generalization beyond the recorded trace |
| Geometry / forces / 3D | Native construction and actual reads | Train-only co-access embedding, Morton order, verified packed reads | Hardware topology and transfer-aware partitioning; no physical-force claim |
| Heterogeneous compute | Actual GPU dispatch | Explicit adapter, shader execution, native CPU oracle | Useful crossover after upload, synchronization and retained-resource costs |
| Compiler pass parallelism | Actual LLVM passes | Dominators/loops and postdominators on private COW module snapshots | Scheduler/analysis invalidation contracts and more expensive independent consumers |
| Speculation | Actual backend execution | Start before exact-IR guard, cancel/wait/discard on hits, private publication | Profitable prediction and bounded CPU/memory waste |
| Shared generations | Actual compiler workers | Sealed memfd inputs, content identity, cooperative leases, private worker state | Other compiler APIs, complete memory accounting and untrusted clients |
| Asset transformation | Actual tools | Decode once versus mature combined/parallel image-tool controls | Larger diverse media and real hardware codecs |
| Runtime refresh | Actual native modules | ABI check, private state, rollback | Broader runtime ownership and live-client contracts |
| Human/agent workspaces | Actual files and AST facts | Private copies, shared read-only files, logical overlays and stale publication | Concurrent consumers and persistent transactions |
| Editor work | Actual parse/compile tasks | Rapid edits, obsolete-task cancellation, current generation | Real language servers and compiler safe points |
| Test preparation | Actual upstream doctests | Fresh interpreters, batching and retained sessions with loaded-source pinning | General fixture isolation and diverse test runners |
| Environment preparation | Actual framework consumer and OCI runs | Copy/symlink/direct configuration plus offline read-only containers | Distribution, writable environments and equal isolation capabilities |
| Representation adapters | Exact roundtrips and rejection tests | Explicit/default/unknown metadata preservation | Real ecosystem evolution and wider schemas |

Adjacent devices such as NPUs, storage controllers and network offload remain capability-dependent prospects. Missing runtime APIs do not establish that physical hardware is absent. No accelerator or compiler result implies arbitrary mutable passes can safely run concurrently.
