# Graph, patch and resource research

The first bounded implementations test when theory can remove work and where it only changes a policy's tradeoff. [Code and reproduction](../../../experiments/science/graphs/README.md), [main report](../../../experiments/science/graphs/results/first-pass/REPORT.md), [geometry report](../../../experiments/science/graphs/results/geometry/REPORT.md), [run index](experiments.json).

The dynamic observation model maintains file lookup, failed candidate, membership, environment and dependency facts. Full/frontier/materialized-relation evaluators produce identical results through cycles, removals and topology changes. On the 200-node generated trace, selective updates improve a complete 24-update sequence from 32.76 to about 3.5 ms, with construction recorded separately. Actual Clang objects match a full oracle on a declared three-TU fixture; captured 33-TU Ninja relations remain historical input rather than a new sound compiler scheduler.

Patch laws work on explicitly supported contexts and preserve full snapshots. The set-join model retains conflicting alternatives, while target publication still needs a serialized expected-generation decision. Neither convergence nor disjoint paths prove code/test/review independence.

The scheduling model shows a large cancellation opportunity under rapid obsolete edits, with smaller differences among cancellation-enabled policies. Foraging lowers some wasted work but does not win latency. A [supplemental calibration](../../../experiments/science/graphs/results/scheduler-calibration/REPORT.md) uses measured real frontend/compile/test/search command durations and retains that broad pattern. The queue and cancellation remain simulated; the synchronous compiler host has no real safe-point callback.

The memory model counts dependency leases and scratch. Recency outperforms a simple immediate cost/size rule in one shared-intermediate trace; an offline oracle establishes the remaining tiny-model gap. Coarse module boundaries can over-invalidate 20 roots where the same fine graph requires one.

Native 1D/3D force layouts improve lexical ordering on a real co-access input but lose to cheaper BFS and ordinary greedy clustering. Logical geometry is not hardware placement, and another fresh start of the same workload is not an unseen-workload generalization test.

The [actual compiler extension](../../../experiments/science/graphs/results/compiler-observations/REPORT.md) connects that boundary to Clang VFS events. A three-TU, eleven-operation trace falls from 261.03 to 116.22 ms with validation and selective compilation, while 192 successful objects and depfiles match a physical compiler oracle. Identical-IR reuse refreshes dependency facts; negative lookup, shadowing, deletion, configuration and stale generations are exercised. External SDK/environment remain fixed inputs, not fully captured effects.

Next use actual scheduled work/cancellation, extend compiler observation coverage beyond the bounded namespace, and evaluate retention/layout policies on broader held-out workloads. Keep publication, context, transient memory and construction costs explicit. These studies select no public protocol or product architecture.
