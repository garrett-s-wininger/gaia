# Follow-ups justified by these boundaries

A larger independent analysis may amortize COW/fork coordination. Select one real compiler/linter consumer with a declared output oracle and compare a competent serial path before widening the pool. Preserve current-source diagnostics, object-only restrictions and publication/cancellation behavior. Arbitrary mutable optimizer passes need their own dependency/isolation contract.

For source sharing, exercise multiple immutable generations under pressure, cooperative worker crashes, cancellation and bounded reclamation. Measure whole-workflow producer plus worker memory over time before claiming peak RAM reduction. A Rust/C++/JVM consumer could test whether the same immutable byte boundary survives outside Python; it must retain compatible tool behavior and charge its adapter.

Do not prioritize broader speculation on the current evidence. First locate a guarded operation where work overlap exceeds coordination and hit-path waste, using enough independent samples to distinguish small effects. These are research prospects, not implemented production guarantees.
