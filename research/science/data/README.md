# What sets and adaptive data policies establish

These [experiments](../../../experiments/science/data/README.md) turn six scientific directions into bounded comparisons over actual package bytes and recorded consumer accesses. Read the [findings](findings.md), [prospects](prospects.md) and [run index](experiments.json).

The useful outcomes are specific: set sketches reduce metadata while costing more cold CPU; batching matters more than a blanket framing claim; conventional clustering beats the first reinforcement/force policies; ordinary symlinks already capture most environment-copy avoidance; and exact metadata preservation rejects apparently equivalent lossy views.

No result selects a public protocol, proves a native speed limit, demonstrates real WAN/device behavior, or changes the source-control snapshot/history contract.
